Fetch Puppy

Music search and collection tool for macOS

macOS Swift / SwiftUI

Search, discover, and organise your music collection. Fetch Puppy finds tracks across multiple sources, scores results for quality, and converts them into a neatly tagged local library with artwork and metadata.

Features

  • Multi-source search with smart quality scoring
  • Best-in-class audio conversion (MP3, AAC, FLAC)
  • Automatic metadata and artwork tagging
  • Batch processing with drag and drop
  • Background processing with menu bar integration
  • Clean, native macOS interface
