Quicker IP user guide

Updated for version 2.6

Quicker IP is a menu bar app. Everything starts from its icon at the top right of the screen: click it to open the menu, where each network adapter is listed with its current address and status. This guide runs through what each part does and how to use it.

The menu bar icon

The icon can show one of three things, set in Settings under Menu Bar: the IP address, the Wi-Fi name, or live download and upload speed. A coloured status dot sits next to each adapter in the menu, and the menu-bar icon itself can be tinted to match (Settings, Menu Bar, Colour Status Icon). The colours are:

  • Blue - this adapter holds the default route
  • Green - connected with an address
  • Yellow - a self-assigned address (no DHCP reply)
  • Orange - IPv4 off but still live over IPv6 (running on IPv6)
  • Red - no working IP (connected but no address, or IPv4 off with no IPv6)
  • Grey - inactive

Reading an adapter

Each adapter is a header you can expand by clicking it. Active adapters open on first launch; the app remembers your expand and collapse choices after that. Hold Option and click any adapter to collapse or expand them all at once. Collapsed adapters still show their live address on the header row, alongside the Wi-Fi network name and the active preset where there is one, so you can read every adapter at a glance without expanding anything. A header address only appears when it is actually live - expand or hover an adapter to see a static that is configured but not up. Expand an adapter and click More Info to see the full detail:

  • IP, subnet and gateway (click any to copy when Click to Copy is on)
  • DNS servers in use - servers marked "(auto)" in grey came from DHCP, others were set by hand
  • Wi-Fi signal, band, channel and link rate on wireless adapters
  • Live traffic in and out
  • Link speed and duplex - half duplex is shown in red
  • MTU - shown in red if below 1500
  • MAC address
  • A subnet overlap warning if two adapters share a range

Link speed, duplex, MTU and the overlap warning are the Dante monitoring checks: a full-duplex gigabit link at MTU 1500 with no overlapping subnets.

Quicker IP also checks the gateway. If an adapter's gateway is not inside its own subnet, the gateway line turns red and More Info reads "Gateway: Outside subnet, unreachable", because the adapter cannot reach a gateway off its subnet and traffic to other networks will not get out. An adapter that comes up this way raises a one-time Gateway Unreachable alert, and applying a static IP with an off-subnet gateway asks you to confirm first.

Setting an IP address

The first time you change a network setting, macOS asks for your password once. After that, changes apply silently. Hover an adapter's name to open its settings flyout, where you reach these:

  • DHCP - automatic address from the network.
  • DHCP Reserved - keeps your current address but takes subnet and gateway automatically. Click it, enter the address to hold, then Apply.
  • Static IP - enter IP, subnet mask and gateway, then Apply. The subnet defaults to 255.255.255.0 and the gateway is optional.
  • IPv4: Off - switches IPv4 off on this adapter while leaving the link and IPv6 up, so it stays connected but takes no part in IPv4. Use it to keep an adapter on the network (internet over IPv6, AirPlay, Wi-Fi location) while removing it from IPv4 routing - handy in multi-adapter and AV/Dante rigs where you want one interface to own IPv4 - or to stop self-assigned 169.254 addresses and IPv4 subnet or gateway clashes. It does not stop traffic; IPv6 keeps working. The adapter's status dot turns orange to show it is still live over IPv6, or red if there is no IPv6 either, so you can tell at a glance whether anything is still getting through. You can ask the app to confirm first in Settings, Alerts.
  • Renew DHCP - forces a fresh lease. You get a notice telling you whether the address changed.
  • Restore - after turning IPv4 off or applying a preset, returns the adapter to its previous settings.

DNS per adapter

You can set DNS on each adapter on its own, separate from the IP mode. Hover the adapter's name to open its settings flyout, then open the DNS row. The choices are:

  • Automatic - use the DNS servers DHCP hands out
  • Cloudflare - 1.1.1.1 and 1.0.0.1
  • Google - 8.8.8.8 and 8.8.4.4
  • Quad9 - 9.9.9.9 and 149.112.112.112
  • Custom - enter up to three servers in priority order, then Apply

The first DNS change on an existing install asks for your password once to extend permissions, then applies silently after that.

Presets

A preset stores an adapter's mode, IP, subnet and gateway so you can reapply it in one click.

  • Save - expand the adapter, click Save Current as Preset, name it. Saving while on DHCP creates a Reserved preset holding your current address.
  • Apply - open the Presets submenu and click a preset. A filled dot marks the preset active on that adapter.
  • Edit - Edit Presets (in the Presets flyout) lets you rename, change the IP, subnet and gateway, or delete a preset. Drag presets into your preferred order and the menu follows.
  • Restore - after applying a preset, a Restore item returns the adapter to its earlier settings.

Network locations

A location is a full set of network settings you can switch between, for example one for the studio and one for home.

  • Create Location - name it, and tick "Copy all services from [current location]" if you want to start from your current setup. Duplicate names are rejected.
  • Switch - open Network Locations and click one. Change notifications are held back for fifteen seconds so the switch does not spam alerts.
  • Edit Locations - rename or delete a location. Renaming keeps all its services and settings.
  • Service Order - drag services to set their priority, and rename or delete a service. The new order is written to the system when you click Apply.

Scanning the network

Quicker IP can list every device that responds on the network.

  • LAN Scan - expand an adapter and click LAN Scan. It sweeps the local network and reads the ARP table, and adds device names and protocols over mDNS at the same time. Networks up to 1024 addresses are swept in full; on larger networks it sweeps your local /24 and uses ARP and mDNS for the rest. The scan is scoped to the adapter you run it from, so it lists what is actually on that wire, including devices on a different subnet or on link-local (self-assigned 169.254.x.x) addresses sharing the same switch. A live count shows progress.
  • Range Scan - enter a start and end address to scan a custom range, up to 4096 addresses.
  • Ping - enter an address or hostname for a quick latency and packet loss check. The ping goes out through the adapter you clicked, not just the default route, and when you ping an IP it shows the device's name beside it if one can be resolved.

Results open in a panel with columns for IP, MAC, vendor, name and type. The name is the device's friendly Bonjour name, with its model where it advertises one; devices that do not advertise over Bonjour, such as phones, tablets and routers, are named from their network (DHCP) hostname instead. Hover a row to see the full technical hostname. The vendor is read from the MAC address and is blank for devices using a private, randomised MAC: many phones, tablets and watches rotate their address for privacy, so it matches no manufacturer (the name usually identifies them anyway). The type is the network protocol it speaks, such as Dante, NDI, AirPlay or printer, rather than a raw service string. Click an IP to copy it, or right-click a row for Copy MAC. Export to CSV saves the full list, including the raw hostname and service. Devices found on a different subnet show with an orange address.

Join Subnet

When a scan finds a device on a different subnet (shown in orange), right-click it and choose Join Subnet. Quicker IP finds a free address in that device's subnet, applies it to your adapter, and saves your previous settings. Use Restore in the Presets menu to switch back. You can have the app confirm first in Settings, Alerts. After joining, click Rescan and the scan follows your adapter onto the new subnet, since LAN Scan and Rescan always scan the adapter's current network.

Pro audio networks and Dante

Dante and similar gear announce themselves over standard mDNS, so they show up in a scan run on the adapter they are wired to. Dante devices default to DHCP and fall back to a self-assigned link-local address (169.254.x.x) when no DHCP server is present, so a typical rig is a mix: most devices link-local, the odd one left on a static address, or the reverse. Quicker IP lists them all and flags the odd one out in orange, so you can spot a misconfigured unit and use Join Subnet to hop onto it and sort it out. Unlike some control software, which hides a device stranded on the wrong subnet, the scan still shows it.

A note on IGMP snooping. If Dante devices appear and then vanish, or never show up at all, the usual cause is IGMP snooping enabled on the switch without an IGMP querier. Snooping then prunes the multicast that discovery (mDNS) and clocking rely on, and devices drop off. On small or single-switch networks it is often best left off; it helps only on larger networks carrying heavy multicast audio, and then only with a querier configured.

Packet Loss

Packet Loss sits next to Ping in the scan area and is a monitor that runs until you stop it, for keeping an eye on one path over time. Pick a target (it defaults to the gateway) and Quicker IP pings it continuously, bound to the adapter you opened it from, so the test stays on that adapter rather than the default route. A live window shows:

  • Sent, received and lost counts, and loss percent
  • Current, minimum, average and maximum RTT, plus jitter
  • A rolling RTT timeline with dropped packets marked on it

A clean run reads clearly as a healthy path. The severity is worked out from the pattern, so the odd isolated drop is ignored while runs of consecutive losses, sustained loss or latency spikes are flagged. Export to CSV (timestamp, RTT and drop for every ping) so a fault can be lined up with the exact moment it happened. It works on any adapter, including pro audio networks such as Dante, as an early warning on network health.

On Wi-Fi you will usually see latency spikes on a regular beat, often every ten to twenty seconds, with no lost packets at all. That is the radio briefly leaving your channel to look at the other networks around it, and every Mac does it. Spikes that keep time like a metronome are the radio doing its housekeeping; a real fault is irregular, and normally loses packets as well as delaying them. This is also why a wired connection is the fair test of a network path, and why audio networks are run on cable.

Speed test

Click Speed Test in the menu. It measures download, upload, ping and jitter against Cloudflare's network, and takes about twenty seconds. Progress shows in the menu title and you can cancel mid-test. Results stay until you clear them; if a test fails, the app shows an alert and keeps your last result.

Alongside the idle Ping and Jitter, the test also reports a Loaded latency reading. This is the ping measured while the link is saturated, during the download and upload phases, so it shows whether the connection stays responsive under load (bufferbloat). It is graded from good to poor and takes no extra time, as it runs within the same test.

System info panel

Turn on Show Info Panel in Settings, Info Panel, for a small floating panel of system readings: CPU, memory, disk, battery, uptime, gateway latency, DNS response time and Wi-Fi signal. Each reading has its own toggle, and the panel refreshes every ten seconds.

Disk and memory read as used/total, matching About This Mac and Activity Monitor's Memory Used figure, and uptime counts time since boot like the system's own uptime readout. Ping and DNS are live measurements through your current connection.

Wi-Fi

  • Power - turn Wi-Fi on or off from the adapter header, no password needed.
  • Network name - turn on Location Access (SSID) in Settings, General, to show the Wi-Fi name. If the name stays blank, use Open Location Settings to grant access.
  • Signal - a three-arc indicator shows strength as white and grey bars; the Signal reading in More Info is colour-coded from green for strong down to red for weak.

Settings reference

  • General - Public IP display, Click to Copy, Run at Login, Allow Network Changes (Admin), Location Access (SSID), Edit Visible Services, Check for Updates and Manage License. Email Support sits at the bottom: it copies a diagnostics report and opens an email to support.
  • Menu Bar - Colour Status Icon, and the IP Address / Wi-Fi Name / Live Speed display choice.
  • Info Panel - the master Show Info Panel toggle and a switch for each reading.
  • Alerts - IP change notifications, auto pop-ups for speed test and scan results, and the confirm prompts for IPv4 Off, Delete and Join Subnet.

Edit Visible Services lets you hide adapters you never touch. If a change would hide every service, the app beeps and reverts it. It also holds Show Inactive Services. Left on (the default), a disconnected adapter stays in the menu greyed-out so you can still pre-set it - apply a preset or a static IP ready for when it reconnects. Turned off, an unplugged adapter vanishes until it is plugged back in, so switch it on if you need to configure one that is not currently connected. Whenever inactive adapters are hidden, a Show N Hidden Adapters row appears at the foot of the menu as a one-click shortcut to bring them back.

Licence and activation

Quicker IP Pro is a one-time purchase with two activations per licence key. On first launch, paste your key to activate. To move the licence to another Mac, open Manage License in Settings and deactivate, which frees an activation. The app revalidates occasionally; a network error never removes your licence, only an explicit revocation (cancelled, expired, disabled or inactive) does.

Pro and Lite

This guide covers Quicker IP Pro. The free Lite version on the Mac App Store shows your adapters, addresses and MAC, the public IP, click to copy, status dots and run at login, but does not change network settings, scan, run a speed test, or manage DNS, presets and locations.
