Quicker IP user guide

Updated for version 2.4

Quicker IP is a menu bar app. Everything starts from its icon at the top right of the screen: click it to open the menu, where each network adapter is listed with its current address and status. This guide runs through what each part does and how to use it.

The menu bar icon

The icon can show one of three things, set in Settings under Menu Bar: the IP address, the Wi-Fi name, or live download and upload speed. A small status dot can sit on the icon (Settings, Menu Bar, Colour Status Icon). The dot colours are:

  • Cyan - this adapter holds the default route
  • Green - connected with an address
  • Yellow - a self-assigned address (no DHCP reply)
  • Orange - up but no IP
  • Grey - inactive
  • Red - IPv4 is switched off on the adapter

Reading an adapter

Each adapter is a header you can expand by clicking it. Active adapters open on first launch; the app remembers your expand and collapse choices after that. Expand an adapter and click More Info to see the full detail:

  • IP, subnet and gateway (click any to copy when Click to Copy is on)
  • DNS servers in use - servers marked "(auto)" in grey came from DHCP, others were set by hand
  • Wi-Fi signal, band, channel and link rate on wireless adapters
  • Live traffic in and out
  • Link speed and duplex - half duplex is shown in red
  • MTU - shown in red if below 1500
  • MAC address
  • A subnet overlap warning if two adapters share a range

Link speed, duplex, MTU and the overlap warning are the quick Dante readiness checks: you want a full-duplex gigabit link at MTU 1500 with no overlapping subnets.

Setting an IP address

The first time you change a network setting, macOS asks for your password once. After that, changes apply silently. Expand an adapter to reach these:

  • DHCP - automatic address from the network.
  • DHCP Reserved - keeps your current address but takes subnet and gateway automatically. Click it, enter the address to hold, then Apply.
  • Static IP - enter IP, subnet mask and gateway, then Apply. The subnet defaults to 255.255.255.0 and the gateway is optional.
  • IPv4: Off - turns IPv4 off on the adapter. You can ask the app to confirm first in Settings, Alerts.
  • Renew DHCP - forces a fresh lease. You get a notice telling you whether the address changed.
  • Restore - returns the adapter to the mode it had before the last change.

DNS per adapter

You can set DNS on each adapter on its own, separate from the IP mode. Expand the adapter and open the DNS row. The choices are:

  • Automatic - use the DNS servers DHCP hands out
  • Cloudflare - 1.1.1.1 and 1.0.0.1
  • Google - 8.8.8.8 and 8.8.4.4
  • Quad9 - 9.9.9.9 and 149.112.112.112
  • Custom - enter up to three servers in priority order, then Apply

The first DNS change on an existing install asks for your password once to extend permissions, then applies silently after that.

Presets

A preset stores an adapter's mode, IP, subnet and gateway so you can reapply it in one click.

  • Save - expand the adapter, click Save as Preset, name it. Saving while on DHCP creates a Reserved preset holding your current address.
  • Apply - open the Presets submenu and click a preset. A green tick marks the one currently active.
  • Edit - Edit Presets (in the Presets flyout, or Settings, General) lets you rename, change the IP, subnet and gateway, or delete a preset.
  • Restore - after applying a preset, a Restore item returns the adapter to its earlier settings.

Network locations

A location is a full set of network settings you can switch between, for example one for the studio and one for home.

  • Create Location - name it, and tick "Copy all services from [current location]" if you want to start from your current setup. Duplicate names are rejected.
  • Switch - open Network Locations and click one. Change notifications are held back for fifteen seconds so the switch does not spam alerts.
  • Edit Locations - rename or delete a location. Renaming keeps all its services and settings.
  • Service Order - drag services to set their priority, and rename or delete a service. The order syncs to the system when you close the panel.

Scanning the network

Quicker IP can list every device that responds on the network.

  • LAN Scan - expand an adapter and click LAN Scan. It sweeps the local network and reads the ARP table, and adds hostnames and service names over mDNS at the same time. Networks up to 1024 addresses are swept in full; on larger networks it sweeps your local /24 and uses ARP and mDNS for the rest. A live count shows progress.
  • Range Scan - enter a start and end address to scan a custom range, up to 4096 addresses.
  • Ping - enter an address or hostname for a quick latency and packet loss check. The ping goes out through the adapter you clicked, not just the default route.

Results open in a panel with columns for IP, MAC, vendor, hostname, Bonjour service and how the device was found. Click an IP or MAC to copy it. Export to CSV saves the full list. Devices found on a different subnet show with an orange address.

Join Subnet

When a scan finds a device on a different subnet (shown in orange), right-click it and choose Join. Quicker IP finds a free address in that device's subnet, applies it to your adapter, and saves your previous settings. Use Restore in the Presets menu to switch back. You can have the app confirm first in Settings, Alerts.

Speed test

Click Speed Test in the menu. It measures download, upload, ping and responsiveness against Apple's network, and takes about twenty seconds. Progress shows in the menu title and you can cancel mid-test. Results stay until you clear them; if a test fails, the app tells you and keeps your last result rather than wiping it.

System info panel

Turn on Show Info Panel in Settings, Info Panel, for a small floating panel of system readings: CPU, memory, disk, battery, uptime, gateway latency, DNS response time and Wi-Fi signal. Each reading has its own toggle, and the panel refreshes every ten seconds.

Wi-Fi

  • Power - turn Wi-Fi on or off from the adapter header, no password needed.
  • Network name - turn on Location Access (SSID) in Settings, General, to show the Wi-Fi name. macOS asks for location permission the first time.
  • Signal - a three-arc indicator shows strength, coloured from green for strong down to red for weak.

Settings reference

  • General - Public IP display, Click to Copy, Run at Login, Allow Network Changes (Admin), Location Access (SSID), Edit Visible Services, Edit Presets, Check for Updates and Manage License.
  • Menu Bar - Colour Status Icon, and the IP Address / Wi-Fi Name / Live Speed display choice.
  • Info Panel - the master Show Info Panel toggle and a switch for each reading.
  • Alerts - IP change notifications, auto pop-ups for speed test and scan results, and the confirm prompts for IPv4 Off, Delete and Join Subnet.

Edit Visible Services lets you hide adapters you never touch. If a change would hide every service the app beeps and undoes it, so the menu can never end up empty.

Licence and activation

Quicker IP Pro is a one-time purchase with two activations per licence key. On first launch, paste your key to activate. To move the licence to another Mac, open Manage License in Settings and deactivate, which frees an activation. The app revalidates occasionally; a network error never removes your licence, only an explicit cancellation does.

Pro and Lite

This guide covers Quicker IP Pro. The free Lite version on the Mac App Store shows your adapters, addresses and MAC, click to copy, status dots and run at login, but does not change network settings, scan, run a speed test, or manage DNS, presets and locations.
