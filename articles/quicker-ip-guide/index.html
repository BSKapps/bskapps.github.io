Quicker IP user guide

Updated for version 2.11

Quicker IP is a menu bar app. Everything starts from its icon at the top right of the screen: click it to open the menu, where each network adapter is listed with its current address and status. This guide runs through what each part does and how to use it.

The menu bar icon

Next to the icon you can show the IP address, the Wi-Fi name, live download and upload speed, or nothing at all: pick one from Show in Settings, Menu Bar. A coloured status dot sits next to each adapter in the menu, and the menu-bar icon itself can be tinted to match (Settings, Menu Bar, Colour Status Icon). The colours are:

  • Blue - this adapter holds the default route
  • Green - connected with an address
  • Yellow - a self-assigned address (no DHCP reply)
  • Orange - IPv4 off but still live over IPv6 (running on IPv6)
  • Red - no working IP (the adapter is plugged in but has no cable or no address yet, or IPv4 is off with no IPv6)
  • Grey - inactive (the adapter is not plugged in, or Wi-Fi is off)

For a moment after login or waking from sleep, while Quicker IP reads the current state, the icon is grey, DHCP addresses, Wi-Fi names and the public IP are blank, static and reserved addresses show greyed, and nothing can be changed until the first read is in.

Reading an adapter

Each adapter is a header you can expand by clicking it. Active adapters open on first launch; the app remembers your expand and collapse choices after that. Hold Option and click any adapter to collapse or expand them all at once. Collapsed adapters still show their live address on the header row, alongside the Wi-Fi network name and the active preset where there is one, so you can read every adapter at a glance without expanding anything. A header address only appears when it is actually live - expand or hover an adapter to see a static that is configured but not up. Expand an adapter and click Network Info to see the full detail:

  • IP, subnet and gateway (click any to copy when Click to Copy is on)
  • DNS servers in use - servers marked "(auto)" in grey came from DHCP, others were set by hand
  • Wi-Fi signal, band, channel and link rate on wireless adapters
  • Live traffic in and out
  • Link speed and duplex - half duplex is shown in red
  • MTU - shown in red if below 1500
  • MAC and IPv6 address
  • Multicast - whether the adapter can carry the multicast traffic Dante and AES67 depend on
  • Tx Errors, Rx Errors and Collisions, counted from a baseline you can reset with Clear Counters so only new faults show
  • IGMP Query - reads "active (Ns ago)" or "no querier" when nothing on the network is querying. This row and the clock rows are not shown while an adapter is red (plugged in, no working IP)
  • Audio Clock, Clock Leader and Clock Sync - the PTP audio clock seen on the network, which device is leading it, and whether it is still in sync. On a Dante network Clock Leader names the same device Dante Controller shows as leader, by its Dante name, even when another clock shares the network. A PTPv2 clock, such as one from AES67 gear, gets its own PTPv2 Leader row. If two devices both try to lead, Clock Sync says so. All three read "none found" on a network with no clock
  • A subnet overlap warning if two adapters share a range, and a duplicate IP warning if two live adapters hold the same address. A static adapter that is unplugged shows a greyed "Would overlap" note when its configured subnet matches a live one, so a clash is visible before the cable goes in

Link speed, duplex, MTU and the overlap warning are the Dante monitoring checks: a full-duplex gigabit link at MTU 1500 with no overlapping subnets. Multicast, IGMP Query and the three clock rows cover the rest of an AV network - multicast getting through, a querier keeping it flowing, and a clock the devices can lock to.

Quicker IP also checks the gateway. If an adapter's gateway is not inside its own subnet, the gateway line turns red and Network Info reads "Gateway: Outside subnet, unreachable", because the adapter cannot reach a gateway off its subnet and traffic to other networks will not get out. An adapter that comes up this way raises a one-time Gateway Unreachable alert, and applying a static IP with an off-subnet gateway asks you to confirm first.

Setting an IP address

The first time you change a network setting, macOS asks for your password once. After that, changes apply silently. Hover an adapter's name to open its settings flyout, where you reach these:

  • DHCP - automatic address from the network.
  • DHCP Reserved - keeps your current address but takes subnet and gateway automatically. Click it, enter the address to hold, then Apply.
  • Static IP - enter IP, subnet mask and gateway, then Apply. The subnet defaults to 255.255.255.0 and the gateway is optional.
  • IPv4: Off - switches IPv4 off on this adapter while leaving the link and IPv6 up, so it stays connected but takes no part in IPv4. Use it to keep an adapter on the network (internet over IPv6, AirPlay, Wi-Fi location) while removing it from IPv4 routing - handy in multi-adapter and AV/Dante systems where you want one interface to own IPv4 - or to stop self-assigned 169.254 addresses and IPv4 subnet or gateway clashes. It does not stop traffic; IPv6 keeps working. The adapter's status dot turns orange to show it is still live over IPv6, or red if there is no IPv6 either, so you can tell at a glance whether anything is still getting through.
  • Renew DHCP - forces a fresh lease, and says so if no DHCP server answers. You get a notice telling you whether the address changed.
  • Restore - after turning IPv4 off or applying a preset, returns the adapter to its previous settings.
  • Add Address - puts a second address on a wired port as its own service, ordered below the first with no gateway. Use it when one switch carries two subnets, such as a Yamaha console's Mixer Control and Device Control. The adapter needs its own DHCP or Static address first, so Add Address is greyed on an adapter with no address or a 169.254 one, and it refuses a 169.254 second address, the range macOS assigns by itself, as well as a subnet's own first and last addresses. The new service appears as its own adapter row; rename or delete it through Edit Service.

DNS per adapter

You can set DNS on each adapter on its own, separate from the IP mode. Hover the adapter's name to open its settings flyout, then open the DNS row. The choices are:

  • Automatic - use the DNS servers DHCP hands out
  • Cloudflare - 1.1.1.1 and 1.0.0.1
  • Google - 8.8.8.8 and 8.8.4.4
  • Quad9 - 9.9.9.9 and 149.112.112.112
  • Custom - enter up to three servers in priority order, then Apply

The first DNS change on an existing install asks for your password once to extend permissions, then applies silently after that.

Presets

A preset stores an adapter's mode, IP, subnet and gateway so you can reapply it in one click.

  • Save - expand the adapter, click Save Current as Preset, name it. Saving while on DHCP creates a Reserved preset holding your current address.
  • Apply - open the Presets submenu and click a preset. A filled dot marks the preset active on that adapter. A preset other adapters hold shows their ports, such as en8, in italics after its name (with a count when more than two); hover the row for the adapter names.
  • Edit - Edit Presets (in the Presets flyout) lets you rename, change the IP, subnet and gateway, or delete a preset. Opened from an adapter, the preset that adapter is on is outlined. Drag presets into your preferred order and the menu follows.
  • Restore - after applying a preset, a Restore item returns the adapter to its earlier settings.

Network locations

A location is a full set of network settings you can switch between, for example one for the studio and one for home.

  • Create Location - name it, and tick "Copy all services from [current location]" if you want to start from your current setup. Duplicate names are rejected.
  • Switch - open Network Locations and click one. Change notifications are held back for fifteen seconds so the switch does not spam alerts, whether you switch here or in System Settings.
  • Edit Locations - rename or delete a location, click New Location to add one, or select a location and click Switch to move to it. Renaming keeps all its services and settings.
  • Edit Services - open it here, or from Edit Service in any adapter's flyout. Drag services to set their priority, rename or delete a service, or click Add Service to add one for new hardware. Each row's switch shows or hides that service in the menu straight away; one service always stays visible. Every row shows its port, such as en8, so two services with the same name on different ports can be told apart, and a long name scrolls when you hover it. The service you opened it from is outlined so you can find it in a long list, and a greyed name is marked (hidden) or (inactive) to say why it is not in the menu. A new order is written to the system when you click Apply.

Each location keeps its own hidden and expanded services, and renaming a location keeps its preset ticks and Restore rows. Show Inactive Services sits at the top of Edit Services. Off (the default), an inactive adapter leaves the menu until it comes back, and a Show N Inactive Adapters row at the foot of the menu brings them back in one click. On, an inactive adapter stays in the menu greyed-out so you can still pre-set it - apply a preset or a static IP ready for when it reconnects.

Scanning the network

Quicker IP can list every device that responds on the network.

  • LAN Scan - expand an adapter and click LAN Scan. It sweeps the local network and reads the ARP table, and adds device names and protocols over mDNS at the same time. Networks up to 1024 addresses are swept in full; on larger networks it sweeps your local /24 and uses ARP and mDNS for the rest. The scan is scoped to the adapter you run it from, so it lists what is actually on that wire, including devices on a different subnet or on link-local (self-assigned 169.254.x.x) addresses sharing the same switch. A live count shows progress.
  • Range Scan - enter a start and end address to scan a custom range, up to 4096 addresses, or type a subnet such as 192.168.1.0/24 in Start IP and both fields fill in. The last three ranges you scan are kept in a Recent list at the top of the dialog, which fills both fields back in.
  • Ping - enter an address or hostname for a quick latency and packet loss check. The ping goes out through the adapter you clicked, not just the default route, and when you ping an IP it shows the device's name beside it if one can be resolved.

Results open in a panel with columns for IP, MAC, vendor, name and type. The name is the device's friendly Bonjour name, with its model where it advertises one; devices that do not advertise over Bonjour, such as phones, tablets and routers, are named from their network (DHCP) hostname instead. Hover a row to see the full technical hostname. To list hostnames instead, right-click any column heading and choose Show Hostnames; the column reads Hostname and hovering shows the name. The vendor is read from the MAC address and shows Private address for devices using a private, randomised MAC: many phones, tablets and watches rotate their address for privacy, so it matches no manufacturer (the name usually identifies them anyway). The type lists every network protocol the device speaks, such as Dante, SSC, Blackmagic, QLab, NDI, AirPlay or printer, rather than a raw service string. Shure receivers found on their control port are named and labelled Control. A Yamaha console shows Device Control on the address it uses to talk to Shure receivers and Rio racks, and Mixer Control on the address Editor and StageMix connect to; Yamaha requires those two on different subnets, and the console and its receivers on the same IP method. Hover the Type when a Yamaha row breaks either rule and the note says which. Lighting nodes and desks that answer Art-Net, or that are sending sACN, are named and labelled Art-Net or sACN. Click a column heading to sort by it. Columns size themselves to the results, and the layout you set is remembered between scans; the address and vendor columns still widen when a scan brings in longer entries. Click an IP to copy it, or right-click a row for Copy MAC. Export to CSV saves the full list, with the protocols under a Type column using the same labels as the panel. Devices found on a different subnet show with an orange address. Results stay until you clear them or switch network location; if the adapter's network has changed since the scan, the flyout says so. Windows PCs and other gear with no Bonjour name are named over NetBIOS where they answer. Range Scan also lists devices that ignore ping when they answer on their web, secure web or SSH port.

Join Subnet

An address shown in red is claimed by more than one device, or is a Shure receiver running its Dante audio and Shure control on one IP when each needs its own; each claimant gets its own row. Hover the address for the detail.

When a scan finds a device on a different subnet (shown in orange), right-click it and choose Join Subnet. Quicker IP checks that none of your other adapters is already on that subnet (if one is, it says which and stops), then finds a free address in the device's subnet and applies it to your adapter straight away, saving your previous settings first. A notification gives the new address once it has joined. Use the Restore row in the adapter's menu to switch back. After joining, click Rescan and the scan follows your adapter onto the new subnet, since LAN Scan and Rescan always scan the adapter's current network. During a join, Rescan shows the addresses being tried; it is greyed while an IP change or another scan is in progress, or while the adapter has no address.

Pro audio networks and Dante

Dante and similar gear announce themselves over standard mDNS, so they show up in a scan run on the adapter they are wired to. Dante devices default to DHCP and fall back to a self-assigned link-local address (169.254.x.x) when no DHCP server is present, so a typical system is a mix: most devices link-local, the odd one left on a static address, or the reverse. Quicker IP lists them all and flags the odd one out in orange, so you can spot a misconfigured unit and use Join Subnet to hop onto it and sort it out. Unlike some control software, which hides a device stranded on the wrong subnet, the scan still shows it.

A note on IGMP snooping. If Dante devices appear and then vanish, or never show up at all, the usual cause is IGMP snooping enabled on the switch without an IGMP querier. Snooping then prunes the multicast that discovery (mDNS) and clocking rely on, and devices drop off. On small or single-switch networks it is often best left off; it helps only on larger networks carrying heavy multicast audio, and then only with a querier configured.

Packet Loss

Packet Loss sits next to Ping in the scan area and is a monitor that runs until you stop it, for keeping an eye on one path over time. Pick a target (it defaults to the gateway) and Quicker IP pings it continuously, bound to the adapter you opened it from, so the test stays on that adapter rather than the default route. A live window shows:

  • Packets - sent, received and lost counts, and loss percent
  • Round Trip - the current, average, minimum and maximum round-trip time, plus jitter
  • A rolling timeline of every ping - a blue bar for its round-trip time, yellow for a spike far above the recent norm, and a red line for each lost ping

A status line above the chart reads Waiting... until the first ping, then Healthy, Degraded or Loss Detected. Any lost ping in the last minute reads Degraded, as does a latency spike while it lasts; two lost in a row, or three or more in the last minute, reads Loss Detected. Export to CSV (timestamp, RTT and drop for every ping) so a fault can be lined up with the exact moment it happened. It works on any adapter, including pro audio networks such as Dante, as an early warning on network health.

On Wi-Fi you will usually see latency spikes on a regular beat, often every ten to twenty seconds, with no lost packets at all. That is the radio briefly leaving your channel to look at the other networks around it, and every Mac does it. Spikes that keep time like a metronome are the radio doing its housekeeping; a real fault is irregular, and normally loses packets as well as delaying them. This is also why a wired connection is the fair test of a network path, and why audio networks are run on cable.

Speed test

Click Speed Test in the menu. It measures download, upload, ping and jitter against Cloudflare's network, and takes about twenty seconds. Progress shows in the menu title and you can cancel mid-test. The results also name the adapter the test ran over, the one carrying your internet when it started. Results stay until you clear them; if a test fails, the app shows an alert and keeps your last result.

Alongside the idle Ping and Jitter, the test also reports a Loaded latency reading. This is the ping measured while the link is saturated, during the download and upload phases, so it shows whether the connection stays responsive under load (bufferbloat). It is graded from good to poor and takes no extra time, as it runs within the same test.

System info panel

Turn on Show Info Panel in Settings, Info Panel, for a small floating panel of system readings: CPU, memory, disk, battery, uptime, gateway latency, DNS response time and Wi-Fi signal. Each reading has its own toggle, and the panel refreshes every ten seconds.

Disk and memory read as used/total, matching About This Mac and Activity Monitor's Memory Used figure, and uptime counts time since boot like the system's own uptime readout. Ping and DNS are live measurements through your current connection. Ping times the gateway of your main connection; if any of its last ten pings went unanswered it adds the count in yellow, and it reads timeout in yellow when the gateway stops answering. Some routers, often on venue and guest Wi-Fi, never answer ping at all; then it reads no reply in grey.

Wi-Fi

  • Power - turn Wi-Fi on or off from the adapter header, no password needed. When Wi-Fi is off its row reads Wi-Fi Off, with a Turn Wi-Fi On item beneath it; while inactive adapters are hidden, Turn Wi-Fi On sits near the top of the menu instead.
  • Network name - turn on Location Access (SSID) in Settings, General, to show the Wi-Fi name. If the name stays blank, use Open Location Settings to grant access.
  • Signal - a three-arc indicator shows strength as white and grey bars; the Signal reading in Network Info is colour-coded from green for strong down to red for weak.

Settings reference

  • General - Public IP display, Summary When Collapsed, Click to Copy, Run at Login, Allow Network Changes (Admin), Location Access (SSID), Check for Updates and Manage License. When an update is found in the background, an Update Available item waits under Settings at the top of the menu instead of a window appearing on its own. Email Support sits at the bottom: it copies a diagnostics report and opens an email to support.
  • Menu Bar - Colour Status Icon, and Show, which picks what sits next to the icon: Nothing, IP Address, Wi-Fi Name or Live Speed.
  • Info Panel - the master Show Info Panel toggle and a switch for each reading.
  • Alerts - Network Notifications, auto pop-ups for speed test and scan results, and Confirm Delete. Network Notifications cover an adapter connecting or disconnecting, an adapter being removed, a self-assigned address, a DHCP lease renewing or failing to renew, Join Subnet joining a subnet, a gateway that is unreachable, a gateway that clashes with another adapter's subnet, and an adapter name being reset to its hardware default (macOS does this on its own after some updates and network changes, and it can break anything matching on the name), and two network services sharing a name, with a pointer to rename one in Edit Services so they can be told apart. Notifications name the adapter with its port, such as Dante (en8). On wired adapters carrying an audio clock, a notification also fires when a different device takes over as clock leader.

To uninstall, turn off Allow Network Changes (Admin) first, then drag the app to the Trash. Turning the toggle off removes the admin access it installed; deleting the app alone leaves it behind.

Licence and activation

Quicker IP Pro is a one-time purchase with two activations per licence key. On first launch, paste your key to activate. To move the licence to another Mac, open Manage License in Settings and deactivate, which frees an activation. The app revalidates occasionally; a network error never removes your licence, only an explicit revocation (cancelled, expired, disabled or inactive) does.

Pro and Lite

This guide covers Quicker IP Pro. The free Lite version on the Mac App Store shows your adapters with their real names and modes (DHCP, Reserved, Static or IPv4 Off), addresses, subnet, gateway and MAC, IPv6 and subnet overlap warnings in Network Info, the summary line on collapsed adapters, the public IP, click to copy, status dots, change notifications and run at login. It does not change network settings, scan, run a speed test, or manage DNS, presets and locations.
