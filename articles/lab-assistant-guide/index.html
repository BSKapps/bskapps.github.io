Lab Assistant user guide

Updated for version 2.3

Lab Assistant prepares a QLab workspace in bulk. You pick cues in QLab, choose which jobs to run, and Lab Assistant works through them: setting levels, trimming silence, routing outputs, numbering, colouring, and more. It talks to QLab 5 (and QLab 4). This guide covers what each module does and how to use it.

Connecting to QLab

Open your workspace in QLab, then open Lab Assistant. The sidebar shows a status dot, green for connected, red for no QLab, with the workspace name in the toolbar. Click Open QLab if it is not running. Lab Assistant follows the cues you select in QLab and keeps in step as you change the selection.

Selecting cues

Select the cues you want in QLab, or click Select All to grab every audio and video cue in the current cue list. The filter dropdown narrows this to All, Audio, Video, or Audio and Video. The sidebar shows how many cues (and groups) are selected.

Running modules

Each module has an on/off toggle and its own Run button, so you can run one job on its own. Run All runs every enabled module in sequence across the selected cues. A progress bar and elapsed time show during a run, and you can cancel at any point. You can have Lab Assistant confirm before a run in Settings. Destructive modes (the reset and clear options below) disarm themselves when the app restarts, so they never fire by surprise.

Levels

Measures each cue's loudness and sets its fader so every cue sits at a consistent level. Pick a target:

  • Film / Streaming - -14 LUFS
  • Theatre / Live Performance - -18 LUFS (default)
  • EBU R128 Broadcast - -23 LUFS
  • US Broadcast (ATSC A/85) - -24 LUFS
  • Reset Levels - sets faders back to 0 dB

Turn on the fader offset to land cues at -10 dB instead of at unity, leaving headroom to push a cue during the show. If a cue needs more than QLab's level cap allows, the result flags it so you can see where it ran out of room.

Routing

Two modes, chosen with the picker at the top of the module.

Mono / Stereo fold sends cues to a chosen output pair (1/2, 3/4, 5/6, 7/8): "Mono to Dual Mono" feeds a mono cue to both outputs, "All Cues to Dual Mono" sums stereo to mono and sends it to both, and "Reset Routing" restores channel 1 to output 1 and channel 2 to output 2.

Multi-output routing sends cues to any output or pair, and can sort automatically by name. Turn on Auto-Sort by Name and Lab Assistant classifies cues into Music, VOG and FX buckets by keywords in the cue name or notes, then routes each bucket to its own output pair. You can edit the keywords and the output pairs, and rename the categories. After a run, hover a result row to re-route and re-colour a cue on the spot.

Top and Tail

Trims silence from the start and end of each cue using QLab's start and end times, so cues fire tight. Set the start pad (default 50 ms) and end pad (default 400 ms) to leave a little silence either side. It respects start and end points you have set by hand. The Reset Start and End Points mode clears the trim back to the full file.

Numbering

Four modes:

  • Add Missing Cue Numbers - numbers only the cues that have none, leaving existing numbers alone.
  • Renumber Sequentially - clears and renumbers 1, 2, 3, with an optional prefix (for example Q1, Q2), a custom start and a custom increment.
  • Renumber with Group Sub-Numbers - groups get 1, 2, 3, and their children get 1.01, 1.02, and so on.
  • Clear All Cue Numbers - removes numbers without reassigning.

Fade and Stop

Adds fade-and-stop behaviour so starting one cue fades others out. Choose the scope: Peers (others in the same group), List (the whole cue list), or All (everything running). Set the fade time with the preset buttons (0.5s, 1.0s, 2.0s, 3.0s) or type your own. Reset Fade and Stop removes the behaviour again.

Continue mode

Sets how a cue hands on to the next one: Do Not Continue, Auto-Continue (the next cue starts with this one), or Auto-Follow (the next cue starts when this one finishes).

Colour

Apply Colours colour-codes cues by type (stereo, mono, looped, for audio and video), by category (VOG, FX), and by status (warning, error, group), using a colour map you can edit and reset. Drag a swatch onto a type to reassign it. Clear All Colours removes colours, groups included.

Musical Intelligence

Detects each cue's tempo and key, and can reorder cues for smoother transitions. Detect Only measures BPM and key without moving anything; By Key orders by Camelot-wheel compatibility; By BPM sorts by tempo; Key + BPM groups by compatible key then sorts by tempo within each group. It does not reorder a selection that spans different groups.

Notes

Write module results into each cue's notes during a run (Levels, Routing, Top and Tail, Musical), with Write All and Write None controls. You can clear notes from a single module, clear just Lab Assistant's own notes while keeping yours, or clear all notes.

Mint

Mint is the file-processing window, opened with Mint - Processing in the sidebar. It edits the actual audio (and video) behind your selected cues and writes new files. The pipeline runs in order: noise removal, a seven-band EQ, dual-mono, trim, fade, gain, then normalise.

  • Noise removal with a strength slider.
  • Seven-band EQ (60 Hz to 12 kHz), plus or minus 12 dB per band, with a preview.
  • Trim and fade per file, with a fade preview; an empty end keeps each file's full length.
  • Gain, or Normalise to a LUFS or peak target (gain greys out when normalise is on).
  • Output: format, sample rate, bit depth or bitrate, and channels, with Match Source as the default. Video can be kept, converted, or have its audio extracted.
  • Output mode: Copy and Insert (a new file and a new cue), Append, or Overwrite.

Audition changes before you commit with the preview: pick a cue, choose an output device, set a preview length, and play. Mint processes cues in parallel and, when it creates cues, selects the new ones so they are ready for Run All.

Results

The Results view lists every processed cue with a pass, warning or error icon, a per-module breakdown, and a summary with counts and total run time. Filter chips show All, Errors, Warnings, and each routing destination. You can export the run as a CSV report.

Settings and licence

Open Settings from the gear in the sidebar. It holds updates (with auto-check), your licence (activate or deactivate), which modules are visible, the welcome screen, the confirm-before-processing and completion-summary toggles, and an option to minimise to the menu bar. Lab Assistant is a one-time purchase with two activations.
