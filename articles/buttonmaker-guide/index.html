How to make Stream Deck, Companion and REAPER buttons

14 June 2026

Stream Deck keys, Bitfocus Companion buttons and REAPER toolbars all want custom artwork, and drawing it by hand in an image editor is slow. BSK Button Maker is a free browser tool that designs these buttons for you, with a library of over 200,000 icons. It runs in any browser on Mac or PC, with no sign-up. This is a quick how-to; the tool also has a full Help section built in.

Make a button

Open Button Maker and start from a ready-made preset or a blank button, then:

  • Click Choose icon and search the icon library, or upload your own image.
  • Add a label in the Text card, and set the font, size and position.
  • Set the background to a solid colour, a gradient, or an image.
  • Nudge the icon and text until it reads cleanly at key size.

For a Stream Deck

Click PNG to download the button image, then set it as the key's image in the Stream Deck software. 72 px is the exact size of a key, so it makes the smallest file; 288 px is sharper and scales down cleanly to any key, which is why it is the default.

For Bitfocus Companion

Two ways. Download a PNG and drop it into a button's image box in Companion, or click Companion page to export a whole page file and import it onto an empty page in Companion. The page file carries every button you have designed at once.

For a REAPER toolbar

Click REAPER icons to download a set of toolbar icons as a ZIP (normal, hover and active states, at standard and hi-DPI sizes). Unzip it into REAPER's toolbar_icons folder, then assign each icon to a toolbar button in REAPER's toolbar editor.

Make a whole row at once

If you need a matching set, like CAM 1 to CAM 4 or a numbered cue row, build one button then turn it into a set: add buttons from the picker, or use Number them to fill a range. Download them all as a ZIP, or as a Companion page.

Add an on or active state

For a toggle, give a button a second look for when it is on. Pick Tint, Highlight, Invert or Dot and Button Maker adds a linked on-state button you can fine-tune. A REAPER export pairs it automatically as the button's active icon.

That is the whole loop: design, export, drop it in. Everything stays in the browser, and it is free to use.
