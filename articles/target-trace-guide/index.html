Target Trace user guide

Updated for version 1.0.2

Target Trace is an editor for the target curves used in audio measurement. You shape a curve on a frequency graph and save it as a Smaart .crv file (or a REW house curve). The window has a curve library on the left, the editing canvas in the middle, and a properties panel on the right. This guide covers what each tool does and how to use it.

Starting a curve

The app opens with an empty curve named "My Curve". Start from scratch with the control points and pencil below, or pick a starting shape from New from Preset (press P), or load an existing curve from the library or by dragging a .crv file onto the canvas.

Control points

The curve is a set of points you place and move.

  • Add - double-click an empty spot on the canvas.
  • Move - drag a point. Frequency moves on a log scale, level in dB.
  • Select - click a point; Cmd-click to add more; Shift-click to select a range; Cmd-A for all.
  • Delete - select and press Delete, or use the buttons in the Control Points panel. Clear All empties the curve.
  • Type a value - with one point selected, set its exact Freq and Level in the panel. With several selected, set them all to one Level.

Nudge selected points with Option-arrows (left/right by a semitone, up/down by 0.5 dB). Ctrl-click snaps a point to the cursor.

The pencil

Press D or click Draw to switch to the pencil, then drag to sketch a curve freehand. On release it is simplified to the current band and merged with any points outside the drawn area. Drawing a fresh shape names the curve "My Curve" and resets the offset readout, so a new sketch always starts clean.

TF and Spectrum modes

Switch with the TF and RTA buttons (or T and S).

Transfer Function (TF) is a target relative to a reference level, so 0 dB means "hit the reference at this frequency". TF curves can show a tolerance band and have a TF Reference SPL (default 80 dB). Spectrum / RTA is an absolute dB SPL target and adds smoothing and weighting options. Switching modes converts the points using the reference level, and converts back exactly.

Curve properties

The right panel holds the curve settings:

  • Name - used as the filename when you save.
  • Colour and line weight (1 to 5 pt) for how the curve draws.
  • Tolerance band (TF only) - a shaded plus/minus dB region around the curve.
  • Offset - a running readout of global dB shifts (Cmd-arrows or the plus/minus buttons). Click it to reset. The offset is a working convenience and is never saved into the file.
  • Smoothing (Spectrum only) - Off, 1, 1/3, 1/6, 1/12 octave; a display resolution that does not change your points.
  • Weighting (Spectrum only) - Z (none), A or C; a display-only view that shifts the curve to match how loudness is heard. Flipping back to Z restores the raw shape exactly.
  • TF Reference SPL (TF only) - 60 to 100 dB, the level TF maps to.

Moving around the graph

Arrow keys and the scroll wheel pan and zoom frequency; hold Shift to zoom the dB axis. The toolbar has zoom in, zoom out and reset buttons, and a trackpad pinch zooms frequency. Hovering a point shows its frequency and level. Split View (V) adds a read-only second pane showing the curve in the opposite mode while you edit.

The curve library

The left sidebar lists the .crv files in your Smaart TargetCurves folder. Double-click a curve to load it for editing, drag to reorder, right-click to move to Trash, and tick a curve to overlay it on the canvas for comparison (overlays draw dimmed and read-only). Use the folder button to point at your Smaart install; if the folder goes missing, a notice lets you re-pick it. The All / TF / RTA buttons filter the list by type.

Presets

New from Preset (P) offers Flat, Tilt, 9 dB Haystack, 15 dB Haystack and X-Curve (Cinema). Flat and Tilt have adjustable settings (tilt amount, pivot frequency, and an optional sub bump). Applying a preset replaces the current curve, names it "My Curve" and can be undone.

Simplify

When a curve has more than ten points, a Simplify Points section appears. Pick an octave band and a frequency range and it re-samples the curve onto that grid to tidy it up. Restore brings the original points back.

Saving and exporting

Press Cmd-S to save. The dialog offers two formats: Smaart (.crv) keeps all the metadata (colour, type, tolerance, smoothing band) and the points; REW House Curve (.txt) writes just the frequency and dB columns for use in REW. Saving into your Smaart TargetCurves folder updates the library automatically. REW .txt files are an export only and cannot be loaded back in.

Undo and shortcuts

Cmd-Z undoes any edit, including loads and preset applies; text edits bundle into one undo per field. Handy keys: D draw, T/S modes, V split, P presets, Cmd-A select all, Delete to remove, Option-arrows to nudge a point, Cmd-arrows to shift the whole curve.

Licence and activation

Target Trace is a one-time purchase with two activations. Enter your licence key on first launch. Manage or move the licence from the app menu; a transient network error never locks you out. Check for Updates is in the same menu.
