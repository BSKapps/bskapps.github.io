Companion Modules

Open source Bitfocus Companion modules. Free, MIT licensed.

Two modules for Bitfocus Companion 4+: full Spotify control, and Rational Acoustics Smaart V9 control with live SPL. Both install the same way - import the module package, then follow its short setup below.

Add a module to Companion

Import the module package

Companion 4.x imports a module directly from its .tgz file. Use this until the modules are published to the official Companion list. The steps are the same for either module.

  1. Download the module's .tgz - bsk-spotify-X.Y.Z.tgz or bsk-smaart-X.Y.Z.tgz - from its latest release (links in each module below). Do not extract it.
  2. In Companion, click Modules in the left sidebar.
  3. Click Import module package (the orange button) and select the downloaded .tgz file. The Finder window may open in an unexpected location - navigate to your Downloads folder if needed.
  4. Click Connections in the left sidebar, add a new connection, search for BSK Spotify or BSK Smaart, and select it.
  5. Configure the connection using the module's setup section below.

After Companion updates: in our testing the modules survived a version update intact, but we can't guarantee every update will preserve them. If a connection disappears after an update, re-import the .tgz from the latest release and re-add the connection. Your saved settings and tokens are kept in Companion's database and are usually preserved.

BSK Spotify

Full-featured Spotify Web API controller for Companion. Cue-point playback from a timestamp, named bookmarks, volume fades, album art grids (1x1, 2x2, 3x3), playlist control, 99 ready-made presets, and 30 dynamic variables for track info, timing, and state. Requires a Spotify Premium account and a free Spotify Developer app.

macOS offline fallback: if the Web API drops out mid-show, transport actions keep working via AppleScript and the local Spotify app. Auto-recovers when the API returns.

Set up the Spotify Developer app

The Spotify module needs a free Spotify Developer app for OAuth. One per Companion install is enough. Your normal Spotify account is fine; you do not need a paid developer subscription.

  1. Go to developer.spotify.com/dashboard and sign in with your normal Spotify account.
  2. Click Create app (top right).
  3. Fill in the form:
    • App name: anything works, only you see it. Suggestion: Spotify Control or Companion Spotify.
    • App description: leave blank, or add something short, e.g. BSK Spotify. Only you see it.
    • Website: leave blank.
    • Redirect URIs: type http://127.0.0.1:4115/callback exactly, then click Add. Check that it appears in the list below the input - if it doesn't, it wasn't saved. The URL must be entered exactly as shown, including the port number.
    • Bundle IDs / Android packages: leave blank.
    • Which API/SDKs are you planning to use? tick Web API. Leave the others unticked.
  4. Tick the Terms of Service box and click Save.
  5. You will land on the app's page. Click Settings (top right).
  6. Copy the Client ID. Click View client secret and copy that too. Both go into the Companion connection's Client ID and Client Secret fields.
  7. Back in Companion, click Authenticate on the BSK Spotify connection. A browser tab opens, you sign in to Spotify with your normal account, and authorize. Companion stores the refresh token from then on.
  8. Only if Authenticate fails with an "access denied" or "user not registered" error: go back to the Spotify dev page, switch to the User Management tab, click Add user, and enter your full name and the email tied to your Spotify account. Apps in Development mode sometimes require the authenticating user to be listed here (up to 5 allowed). Then retry Authenticate.

If Authenticate fails with "INVALID_CLIENT" or similar: the most common cause is the Redirect URI in your Spotify app does not match http://127.0.0.1:4115/callback exactly. Whitespace, https vs http, or a trailing slash will all break it. Double-check it appears in the Redirect URIs list and re-save the Spotify app if needed.

BSK Smaart

Control Rational Acoustics Smaart V9 over the Smaart API. Capture traces without the app in focus, start and stop measurements and delay tracking, drive the signal generator, and toggle target curves and views. On Smaart Suite and the Smaart SPL edition, also read live SPL meters - SPL Fast and Slow in Z, A and C weighting, Leq, LAeq, LCeq, Peak, and exposure - straight onto buttons with Smaart's own threshold colours. Live action feedbacks and per-channel SPL variables included.

Live SPL: while SPL logging is running in Smaart, every calibrated channel streams its meter values to Companion. A one-button SPL Logging Start/Stop action arms it from the surface.

Enable the Smaart API

The Smaart module talks to Smaart over its built-in API. No account or developer app is needed, you just enable the API in Smaart.

  1. In Smaart, open Options > Preferences > API.
  2. Tick Enabled and note the Port (default 26000). Set a password only if you want one.
  3. In the Companion connection, enter the IP or hostname of the computer running Smaart (use localhost if Companion and Smaart are on the same machine), the port, and the password if you set one.
  4. Live SPL values need SPL logging running in Smaart. Start it there, or put the module's SPL Logging Start/Stop action on a button.

Commands go over the network, so Smaart does not need to be the front application and can even run on a different computer.
