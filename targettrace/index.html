Target Trace

Target curve editor for Smaart

macOS 14.0+

Build precise target curves for Smaart - from presets, from scratch, or from your own measurements.

Build target curves from presets, draw them freehand, or import and reshape your own measurements. Target Trace gives you a visual editor for Smaart .crv files with drag-and-drop control points, tolerance bands, and one-click export back to Smaart or REW.

Features

  • Visual drag-and-drop control point editing on a logarithmic frequency grid
  • Freehand draw mode - sketch a curve shape and refine it
  • Simplify imported traces - reduce hundreds of points to clean editable curves
  • Preset starting shapes - tilt, haystack, X-curve, sub bump, and more
  • Transfer Function and Spectrum curve types with auto-conversion
  • Tolerance band overlay with adjustable +/- dB range
  • Non-destructive smoothing display (1, 1/3, 1/6, 1/12 octave)
  • Save directly to Smaart TargetCurves folder with automatic index update
  • Export as REW house curve (.txt)
  • Library sidebar - browse all your target curves, filtered by type
  • Adjustable dB scale for both TF and Spectrum modes
  • Multi-point selection with group drag for quick reshaping
  • Full keyboard shortcut support for fast editing

Smaart Compatibility

Target Trace reads and writes native .crv files compatible with all editions of Smaart - Suite, RT, LE, Di, Di2, v8, and v7. Transfer Function targets require Smaart v9.4 or later. Spectrum targets (X-curve, LFE, etc.) work with all versions back to v4/5.

Keyboard Shortcuts

  • D - toggle draw mode
  • T / S - switch Transfer Function / Spectrum
  • P - open preset picker
  • Arrows - pan and zoom the view
  • Shift + arrows - nudge selected points (dB and frequency)
  • Cmd + arrows - global offset and point navigation
  • Cmd + A - select all points
  • Cmd + Z - undo
