Keyboard Shortcuts

  • D - toggle draw mode
  • T / S - switch Transfer Function / Spectrum
  • V - toggle Split View
  • P - open preset picker
  • Left / Right - pan
  • Up / Down - X zoom in / out
  • Shift + Up / Down - Y zoom in / out (follows the pane your cursor is over)
  • Shift + scroll - Y zoom on the cursor pane
  • Opt + arrows - nudge selected point (dB and frequency)
  • Cmd + Left / Right - select previous / next point
  • Cmd + Up / Down - nudge all points in dB
  • Ctrl + click - snap a point to the cursor
  • Cmd + S - save · Cmd + Z - undo · Cmd + A - select all
