MultiViewPort

Multi-window viewer for external displays

macOS Swift / SwiftUI

Turn any external screen into a multi-viewer. MultiViewPort tiles 1, 2, or 4 application windows onto a display with saved presets, focus modes, and a clean menu bar interface. Pick apps from a visual chooser and switch layouts instantly. Built for control rooms, edit suites, and multi-monitor workflows.

Features

  • 1-up, 2-up, and quad-view layouts
  • Visual app picker for each pane
  • Saved layout presets — switch entire setups with one click
  • Focus mode — expand any pane to full screen
  • Menu bar control with live layout preview
  • Works with any external display
  • Clean, native macOS interface

Use Cases

  • AV control rooms — monitor multiple apps on a single display
  • Video editing suites — reference, scopes, and timeline on one screen
  • IT monitoring — dashboards, terminals, and logs side by side
  • Presentations — keep notes, slides, and timer visible together
