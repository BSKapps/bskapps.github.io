Select your QLab cues, enable the modules you need, and hit Run All. Levels are auto-set to your LUFS target, mono routing and crosspoint outputs are configured, silence is trimmed, and cues are numbered and colour-coded - in seconds. Mint adds standalone audio processing and file conversion on top. Built for QLab 5, licensed and free.

Processing Modules

  • Mint - Standalone audio processing: normalisation, 7-band EQ, noise removal, fade in/out, trim, format conversion, and audio extraction from video
  • Levels - Measure integrated LUFS and set QLab fader levels to normalise audio. Four broadcast targets (-24, -23, -18, -14 LUFS), optional -10 dB offset, and reset mode
  • Mono Routing - Set mono cues to dual mono, sum stereo to dual mono, or reset routing to defaults
  • Top & Tail - Detect silence at the start and end of audio cues and set trim points with configurable padding
  • Musical Intelligence - Detect BPM and musical key, then sort cues by Camelot wheel for smooth transitions
  • Colour Code - Customisable colour map for audio, video, and group cues based on type, channels, and status
  • Cue Numbering - Add missing numbers, renumber sequentially, group sub-numbers, or clear all
  • Fade & Stop - Insert fade and stop cues for the same group or entire cue list
  • Continue Mode - Set Do Not Continue, Auto-Continue, or Auto-Follow on selected cues
  • Notes - Write processing results to QLab cue notes, or clear notes from selected cues
  • Auto-switches QLab to Edit mode to make changes, then restores Show mode
