MultiViewPort

Multi-window viewer for external displays

macOS Coming Soon

Turn any external screen into a multi-viewer. MultiViewPort tiles 1, 2, or 4 application windows onto a display with saved presets, focus modes, and a clean menu bar interface. Pick apps from a visual chooser and switch layouts instantly.

  • 1-up, 2-up, and quad-view layouts
  • Visual app picker for each pane
  • Saved layout presets
  • Focus mode — expand any pane to full screen
  • Menu bar control with live layout preview
  • Works with any external display
