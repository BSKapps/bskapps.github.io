QuickIP

Network toolkit for macOS

macOS Swift / SwiftUI

A fast, lightweight network toolkit that lets you view, switch, and manage your IP configuration in seconds. Scan your local network, test connection speeds, and apply saved presets to change your IP setup with one click.

  • Quick IP switching with saved presets
  • IP conflict detection
  • Local network scanner — see every device on your network
  • Built-in speed test
  • Local and public IP address display
  • Menu bar integration for instant access
  • Clean, native macOS interface

Lab Assistant

QLab workspace automation for macOS

macOS Swift / SwiftUI

A companion tool for QLab that takes the grind out of show preparation. Lab Assistant automates the repetitive tasks so you can focus on the creative work. Works with both free and licensed QLab workspaces.

  • Auto-set levels across your workspace
  • Trim start and end silence from audio cues automatically
  • Colour-code cues for quick visual organisation
  • Convert mono files to dual mono with crosspoint routing
  • Batch processing — set up entire shows in minutes

Fetch Puppy

Music search and collection tool for macOS

macOS Swift / SwiftUI

Search, discover, and organise your music collection. Fetch Puppy finds tracks across multiple sources, scores results for quality, and builds a neatly tagged local library with artwork and metadata.

  • Multi-source search with smart quality scoring
  • Automatic metadata and artwork tagging
  • Batch processing with drag and drop
  • Multiple audio formats (MP3, AAC, FLAC)
  • Background processing with menu bar integration
