QuickIP

Network toolkit for macOS

macOS Swift / AppKit

A fast, lightweight network toolkit that lives in your menu bar. View all your network adapters at a glance, switch IP configurations in seconds, scan your local network, and test connection speeds. Built for AV techs, IT professionals, and anyone who needs quick access to their network settings.

Features

  • Monitor all network adapters from the menu bar — Wi-Fi, Ethernet, USB, Thunderbolt, iPhone tethering
  • Live-updating IP, subnet, gateway, and public IP display
  • Colour-coded status dots for instant adapter state recognition
  • Click to copy any IP, subnet, gateway, or MAC address
  • IP change notifications — know immediately when your connection changes
  • Customisable menu bar icon with IP display, SSID, or colour status
  • Run at Login for always-on monitoring

Pro Features

IP Configuration

  • Switch between DHCP, DHCP Reserved, Static, and IPv4 Off
  • IP conflict detection — checks both local adapters and network
  • DHCP Reserved mode locks your IP while keeping auto subnet and gateway
  • Touch ID or password authentication — once per session

Presets

  • Save full IP configs (mode, IP, subnet, gateway) and re-apply with one click
  • Global presets — any preset works on any adapter
  • Visual indicators show which presets are active

Network Scanner

  • Full /24 subnet scan — see every device on your network
  • Custom range scan — up to 1024 hosts
  • Single host ping with min/avg/max/loss stats
  • Shows IP, MAC, vendor, hostname for each device
  • Export results to CSV

Speed Test

  • Built-in speed test using macOS networkQuality
  • Download, upload, ping, and responsiveness (RPM)
  • Live elapsed time in the menu while running

Wi-Fi Details

  • SSID display in menu bar and adapter section
  • Band, channel, signal strength, noise, Tx rate
  • PHY mode, security type, BSSID
  • Colour-coded signal quality indicators
